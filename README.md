# 星辰 OA · 企业级中后台开发平台

基于 **React 19 + TypeScript + Vite + Tailwind CSS v4 + shadcn/ui** 的现代化企业级 OA 基础开发平台模板，开箱即用。

## ✨ 特性

- **多种布局**：侧边布局 / 顶部布局 / 混合布局，实时切换
- **主题系统**：亮色 / 暗色 / 跟随系统，8 种预设主题色 + 自定义取色器，圆角大小可调
- **多标签页**：右键菜单（重新加载 / 固定 / 关闭左侧、右侧、其他、全部）、鼠标中键关闭、标签持久化
- **多级菜单**：支持三级菜单、手风琴模式、折叠为图标栏（悬浮展开子菜单）、徽标数
- **通用页面配置**：偏好设置抽屉（布局、主题、界面开关全部持久化到 localStorage）、面包屑、页脚、内容紧凑模式、灰色 / 色弱辅助模式
- **企业级表格**：基于 TanStack Table 封装 —— 排序、多字段搜索、筛选插槽、列显隐设置、密度切换、全屏、CSV 导出、行选择与批量操作、分页、加载骨架屏、空态
- **全局搜索**：⌘K 命令面板，菜单级联检索
- **OA 业务模块**：工作台、审批中心（发起 / 我的 / 待办 / 已办 / 抄送）、公文管理（收文 / 发文）、会议管理（会议室预订 / 我的会议）、考勤管理（打卡 / 请假 / 出差）、通讯录（部门树）、公告通知、日程管理（月历）、系统管理（用户 / 角色 / 菜单 / 部门 / 岗位）

## 🚀 快速开始

```bash
pnpm install
pnpm dev      # 开发（默认 http://localhost:5173）
pnpm build    # 生产构建
```

登录页任意账号密码均可进入（演示 mock）。

## 📁 目录结构

```
src/
├── components/
│   ├── ui/               # shadcn/ui 基础组件
│   ├── layout/           # 布局系统（侧边/顶部/混合、多标签、设置抽屉…）
│   ├── data-table/       # 企业级表格封装
│   └── page-header.tsx   # 页面标题
├── config/menu.ts        # 菜单树（路由/图标/徽标，改这里即可增删菜单）
├── stores/               # zustand：应用设置 / 多标签 / 认证 / UI
├── lib/theme.ts          # 主题色运行时应用（预设色板在此扩展）
├── pages/                # 业务页面（按模块分目录）
└── App.tsx               # 路由表
```

## 🔧 二次开发

- **新增页面**：在 `src/pages` 建组件 → `App.tsx` 加路由 → `config/menu.ts` 加菜单项，标签页/面包屑/搜索自动生效。
- **新增表格页**：使用 `<DataTable columns={...} data={...} searchKeys={[...]} />`，列定义中设置 `meta.title` 即自动接入列设置与 CSV 导出。
- **对接后端**：mock 数据均在各页面文件内，替换为你的 API 请求即可；登录逻辑在 `stores/auth-store.ts`。
